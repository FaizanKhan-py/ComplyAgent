# Sample policies

These documents are **fictional** and exist only to demonstrate and test the ComplyAgent
knowledge base. They are not real policies of any organisation and are not legal guidance.

| File | Format | Used to show |
|---|---|---|
| `customer_contact_policy.md` | Markdown | contact hours, frequency and channel rules |
| `hardship_assistance_policy.txt` | Plain text | hardship plan eligibility and limits |
| `escalation_policy.pdf` | PDF (2 pages) | page-number citations |
| `messaging_policy.docx` | Word | how collections messages are written: required content, tone by stage, channel rules, prohibited content, reply handling and templates (MG-04) |

`escalation_policy.pdf` is generated by `backend/tests/helpers.py` (`make_pdf`).
